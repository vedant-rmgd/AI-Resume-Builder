# 🚀 AI Resume Builder

An intelligent full-stack Resume Builder application that allows users to create, edit, manage, and share professional resumes with automatic image face-centering and background removal support.

Built using the MERN stack with image processing and public share functionality.

## ✨ Features
**🔐 Authentication**

- User registration & login
- JWT-based authentication
- Protected routes
- Persistent login using localStorage

**📄 Resume Management**
- Create new resumes
- Edit existing resumes
- Save changes instantly
- Real-time preview
- Public/Private resume toggle

**🖼️ Smart Image Handling**

- Upload profile image
- Automatic face-centering
- Otional background removal
- Image re-processing without re-uploading
- Optimized URL-based transformations

**🌍 Public Share Functionality**

- Generate public resume link
- Access public resume without login
- Secure public resume fetching
